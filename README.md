# Englishease
EnglishEase — это Android-приложение для изучения английского языка, которое предлагает пользователям теоретические материалы и интерактивные тесты для проверки знаний. Проект реализован с использованием чистой архитектуры (Clean Architecture) и паттерна MVVM, что обеспечивает модульность, тестируемость и лёгкость поддержки кода.

Стек технологий
- Язык: Kotlin
- База данных: Room (SQLite)
- Аутентификация: Firebase Authentication
- Асинхронность: Coroutines
- Архитектурные компоненты: ViewModel, LiveData

Проект разделён на три основных слоя:
- data – работа с источниками данных (локальная БД Room, Firebase).
- domain – бизнес-логика, модели и интерфейсы репозиториев, use cases.
- presentation – ViewModel и фрагменты (UI), реализованные в пакете viewmodel.

Локальная БД содержит четыре таблицы:
- test – информация о тестах (название, текст теории, количество вопросов).
- question – вопросы для каждого теста (текст вопроса, варианты ответов, баллы за каждый вариант).
- result – результаты прохождений (имя пользователя, баллы, дата).
- text_result – текстовые заключения по диапазонам баллов для вывода после теста.
Связи организованы через внешние ключи с каскадным удалением.
